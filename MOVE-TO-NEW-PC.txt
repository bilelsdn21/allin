0. WHAT THIS FOLDER IS
----------------------------------------------------------------
Three independent projects (all free tools only - never add paid
services):

  1) "check passport"  - Tkinter desktop app. Stamps client ID
     numbers (or their Excel list number as fallback) onto
     passport photos, matches photos against an Excel name list,
     produces report.xlsx (bilingual EN/FR). Entry points:
     app.py (GUI), passport_check.py (CLI), split_pdfs.py
     (multi-passport PDFs -> images). Launched via
     "Passport Check.bat" or a desktop shortcut.

  2) "BUS PROJECT"     - Streamlit app (app.py) + export.py,
     works on the .xlsm files in the folder.

  3) "see placess"     - Flask app (app.py) + report/reconcile
     scripts + seeplaces_downloader.py (Selenium). history.db
     is live data - it must travel with the folder.

  The folder "khd" is NOT moved - if a script references it,
  tell the user instead of recreating it.

2. CLAUDE: ENVIRONMENT SETUP  (mostly automatic)
----------------------------------------------------------------
2.1  Run the setup checker that travels with this folder:

       SETUP.bat            (user can just double-click it)
       - or -
       python setup_check.py

     It checks Python/tkinter/pythonw/Chrome and every library
     all 3 projects need, and installs ONLY what is missing
     (never reinstalls what is already there - no wasted time,
     memory, or prompts). It ends with a PASS/FAIL report.
     Run it FIRST and only fix by hand what it flags:

       - "Python is NOT installed"  -> user installs Python 3.11+
         from the Microsoft Store, then runs SETUP.bat again.
       - "tkinter" missing          -> reinstall Python with the
         tcl/tk option ticked (pip cannot fix this).
       - "pip install failed"       -> check internet, retry.
       - "Chrome not found"         -> only needed for the
         'see placess' downloader; ask the user before
         installing anything.

     To re-verify without installing:  python setup_check.py --check

2.2  Do NOT run manual pip installs unless setup_check.py
     failed and you understand why. The list of requirements
     lives in ONE place: the REQUIREMENTS dict inside
     setup_check.py - update that file if a project gains a
     new dependency.
